# Book Contract Management System

A Python application modeling a many-to-many relationship between Authors and Books through Contract agreements.

## Features
- Full object-relational mapping style associations between `Author`, `Book`, and `Contract`.
- Robust property setters with type validation to maintain domain integrity.
- Automated tracking of total earnings and contract timelines.
